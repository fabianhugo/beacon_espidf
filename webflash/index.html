⚡ BLE Proximity Beacon

Flash the ESP32-C3 beacon firmware straight from your browser — no toolchain needed.

⚠ This browser can't flash. Use Chrome or Edge on a desktop — Web Serial isn't available in Firefox/Safari or on mobile.
⚠ This page must be opened over HTTPS (or localhost).

Plug the board in via USB, click, then pick its serial port in the dialog.

Before you start

  • Use Chrome or Edge on a desktop computer.
  • Connect the ESP32-C3 board with a data USB cable (not charge-only).

If it won't connect

The running firmware light-sleeps, which can stop the chip from auto-entering the download mode. If the connect step fails or times out, put the board in bootloader mode by hand, then click again:

  1. Hold the BOOT button.
  2. Tap RESET (or briefly unplug/replug USB) while still holding BOOT.
  3. Release BOOT, then retry Connect & Install.

Your pairings are kept

A normal install rewrites only the firmware — saved pairings and the device colour (stored in a separate flash region) survive. Choosing Erase device in the install dialog wipes them and the beacon will re-run its colour picker on next boot.
